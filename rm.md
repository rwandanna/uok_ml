# Machine Learning — University of Kigali

Course materials and study resources for the **Machine Learning** _module 09_ at the **University of Kigali (UoK)**.

This repository organizes the module's class notes, assignments, and past examination papers in one place for learning, revision, and academic reference.

│   └── ...

│   ├── ...
│   └── ...
│

```

### `notes/`

Contains class notes and other learning materials covered during the Machine Learning module.

Topics may include:

- Introduction to Machine Learning
- Supervised Learning
- Unsupervised Learning
- Regression
- Classification
- Clustering
- Feature Engineering
- Model Evaluation
- Neural Networks
- Other topics covered during the module

### `assignments/`

Contains coursework, practical assignments, exercises, and related submission materials.

Assignments are kept here for:

- Practice
- Revision
- Understanding course requirements
- Reviewing previous coursework

### `past papers/`

Contains previous examination papers and revision materials.

Past papers can be used to:

- Identify recurring topics
- Practice examination questions
- Understand question formats
- Test understanding of the module
- Prepare for assessments

## Purpose

The repository is intended to provide a structured reference for the Machine Learning module by keeping course materials together rather than scattered across different locations.

It can be used for:

- 📚 Class revision
- 📝 Assignment preparation
- 📄 Past-paper practice
- 💻 Practical and coding exercises
- 🔎 Reviewing important ML concepts
- 🎓 Examination preparation

## How to Use

Start with the materials in `notes/` to understand the concepts covered in class.

Then use `assignments/` to apply those concepts through coursework and practical exercises.

Finally, use `past papers/` to test your understanding under examination-style conditions.

A recommended workflow is:

```text
Class Notes
    ↓
Understand Concepts
    ↓
Assignments & Exercises
    ↓
Past Papers
    ↓
Revision
    ↓
Examination
```

## Academic Use

This repository is intended primarily for **learning and revision**.

If assignments or assessment materials are provided, use them to understand the underlying concepts and develop your own solutions. Do not submit copied solutions as your own academic work.
